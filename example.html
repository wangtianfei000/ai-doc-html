一、方案概述

本方案是经过大量实践验证的AI时代文档格式最优解，它完美解决了传统Markdown在富媒体支持、交互能力和视觉表达方面的不足，同时保持了AI生成效率高、版本控制友好的优势。

核心思想是使用单文件HTML作为统一载体，同时承载三种不同类型的内容：

  • 富文本文档：使用标准HTML标签配合Tailwind CSS实现专业排版
  • 架构图/流程图：通过Mermaid CDN原生渲染，代码与文档同文件
  • 界面原型：直接嵌入Tailwind CSS组件，支持真实交互

这种三位一体的架构实现了"一次生成，处处使用"，极大提高了文档创作和协作效率。

3.1 JavaScript / TypeScript

typescript 
// 基于 React Hooks 的 AI 文档生成器
import { useState, useCallback } from 'react';

interface DocConfig {
  title: string;
  model: 'gpt-4o' | 'claude-opus' | 'gemini';
  includeMermaid?: boolean;
}

export function useDocGenerator(config: DocConfig) {
  const [loading, setLoading] = useState(false);
  const [content, setContent] = useState<string>('');

  const generate = useCallback(async (prompt: string) => {
    setLoading(true);
    try {
      const res = await fetch('/api/generate', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ ...config, prompt }),
      });
      const data = await res.json();
      setContent(data.html);
    } finally {
      setLoading(false);
    }
  }, [config]);

  return { loading, content, generate };
}

3.2 Python

python 
"""
AI 文档生成服务的 FastAPI 实现
"""
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field
from typing import Literal, Optional
import openai

app = FastAPI(title="AI Doc Generator")

class GenerateRequest(BaseModel):
    prompt: str = Field(..., min_length=10, description="文档生成提示词")
    model: Literal["gpt-4o", "claude-opus"] = "gpt-4o"
    include_mermaid: bool = True
    temperature: Optional[float] = 0.7

@app.post("/api/generate")
async def generate_doc(req: GenerateRequest) -> dict:
    """调用大模型生成完整的 HTML 文档"""
    try:
        response = await openai.ChatCompletion.acreate(
            model=req.model,
            messages=[
                {"role": "system", "content": _build_system_prompt(req)},
                {"role": "user", "content": req.prompt},
            ],
            temperature=req.temperature,
        )
        return {"html": response.choices[0].message.content}
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))

def _build_system_prompt(req: GenerateRequest) -> str:
    base = "你是一个专业的单文件 HTML 文档生成器。"
    if req.include_mermaid:
        base += "请使用 Mermaid 语法绘制架构图。"
    return base

3.3 Java (Spring Boot)

java 
package com.example.aidoc.controller;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;
import lombok.RequiredArgsConstructor;

/**
 * AI 文档生成控制器
 */
@RestController
@RequestMapping("/api/v1/docs")
@RequiredArgsConstructor
public class DocGenerationController {

    private final DocGenerationService docService;

    @PostMapping("/generate")
    public ResponseEntity<DocResponse> generate(@Valid @RequestBody DocRequest request) {
        log.info("Received generation request: model={}", request.getModel());
        DocResponse response = docService.generateDocument(request);
        return ResponseEntity.ok(response);
    }

    @GetMapping("/{docId}")
    public DocResponse getById(@PathVariable Long docId) {
        return docService.findById(docId)
            .orElseThrow(() -> new ResourceNotFoundException("Doc not found: " + docId));
    }
}

3.4 SQL

sql 
-- 创建 AI 文档表与索引
CREATE TABLE ai_documents (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,
    title       VARCHAR(255) NOT NULL COMMENT '文档标题',
    model       VARCHAR(64)  NOT NULL COMMENT '生成模型',
    html_body   MEDIUMTEXT   NOT NULL COMMENT '文档HTML内容',
    token_count INT          DEFAULT 0,
    created_by  BIGINT       NOT NULL,
    created_at  TIMESTAMP    DEFAULT CURRENT_TIMESTAMP,
    updated_at  TIMESTAMP    DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_creator_time (created_by, created_at DESC),
    FULLTEXT KEY ft_title (title)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='AI文档主表';

-- 查询某用户最近 7 天生成的文档Top10
SELECT id, title, model, token_count, created_at
FROM   ai_documents
WHERE  created_by = ?
  AND  created_at >= DATE_SUB(NOW(), INTERVAL 7 DAY)
ORDER  BY created_at DESC
LIMIT  10;

六、快速开始指南

6.1 基本使用方法

  1. 复制本文档的完整HTML代码
  2. 保存为一个扩展名为.html的文件
  3. 用任何现代浏览器打开该文件
  4. 根据你的需求修改内容

6.2 AI生成提示词模板

请生成一个完整的单文件HTML文档，包含以下内容：

1. 文档标题：[你的文档标题]
2. 文档内容：[详细描述文档的各个章节和内容]
3. 架构设计：[详细描述系统架构，包括主要组件和它们之间的关系]
4. 界面原型：[详细描述需要生成的界面原型，包括功能和布局]

技术要求：
- 使用Tailwind CSS v4 CDN进行样式设计
- 使用Mermaid v11 CDN渲染架构图
- 所有代码必须在一个HTML文件中，不依赖任何外部资源
- 文档排版要美观，有合适的间距和字体大小
- 架构图要使用不同颜色区分不同类型的组件
- 界面原型要实现完整的交互逻辑
- 使用响应式设计，适配不同屏幕尺寸

输出要求：
- 只输出完整的HTML代码，不要任何额外的解释
- 确保代码可以直接在浏览器中打开并正常运行
- 所有图片使用https://picsum.photos/占位

6.3 最佳实践

  • 使用<details>标签折叠不重要的内容，降低信息密度
  • 为Mermaid图表添加适当的颜色和样式，提高可读性
  • 将原型放在单独的容器中，与文档内容区分开
  • 使用Git进行版本控制，记录所有修改历史
  • 建立团队共享的组件库和模板库，提高生成效率

七、常见问题

这个方案需要安装任何软件吗？

不需要。所有依赖都通过CDN引入，你只需要一个文本编辑器和一个现代浏览器即可使用。

离线情况下可以使用吗？

可以。你只需要将Tailwind CSS和Mermaid的CDN文件下载到本地，然后修改HTML中的引用路径即可。

如何导出为PDF或Word文档？

导出PDF可以直接使用浏览器的打印功能（Ctrl+P），选择"另存为PDF"。导出Word可以使用Pandoc工具，或者使用浏览器的"另存为"功能保存为HTML后用Word打开。

这个方案适合团队协作吗？

非常适合。HTML是纯文本格式，可以完美支持Git版本控制，团队成员可以同时编辑不同部分，并且可以清晰地看到每次修改的差异。
